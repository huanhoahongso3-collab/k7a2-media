# K7A2 Media Storage

Automated daily storage repository for K7A2 student Facebook media (photos & videos) scraped post-February 2025.

Structure:
- index.json: Global catalog of all students and media item summaries.
- <student_folder>/index.json: Chronological list of photos and videos for each student with post metadata.
- <student_folder>/<media_files>: Filtered media files and thumbnails.
